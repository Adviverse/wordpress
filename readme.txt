Embed Adviverse ad slots with a shortcode or block.

== Description ==
Adds the `[adviverse_ad tag="tk_..." sizes="300x250"]` shortcode and a server-rendered "Adviverse Ad" block. The Adviverse SDK (serve.adviverse.com/sdk/v1.js) loads asynchronously, once, and only on pages that contain a slot.

Get your placement tag from Publisher > Placements in the Adviverse dashboard.

== Installation ==
1. Upload the `adviverse` folder to `/wp-content/plugins/`.
2. Activate the plugin.
3. Add `[adviverse_ad tag="YOUR_TAG" sizes="300x250"]` to a post, or insert the Adviverse Ad block.
